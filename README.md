# Pfand-Rechner (Getränkehandel)

Eigenständige Web-App zum schnellen Berechnen von **Leergut-Annahme** und **Vollgut-Ausgabe** – läuft in Safari (iPhone/iPad), Chrome, Firefox, Edge und Samsung Internet, auch offline.

**Bedienung**
- Oben zwischen *Leergut-Annahme* (grün) und *Vollgut-Ausgabe* (blau) umschalten.
- Auf das Bild oder **+** tippen = 1 Stück mehr, **−** = 1 weniger, auf die Zahl tippen = Anzahl per Ziffernblock eingeben.
- Unten steht immer der Saldo: *Kunde zahlt Pfand* bzw. *An Kunde auszahlen*.
- **Beleg**: Übersicht aller Positionen, optional Warenwert eingeben, Drucken (Bon-Format 80 mm).
- **Neu**: nächster Kunde („Zurück“ macht das rückgängig).
- **Preise**: Pfandwerte anpassen, Artikel ein-/ausblenden, eigene Artikel anlegen (wird im Gerät gespeichert).

**Standard-Pfandwerte** (anpassbar)

| Artikel | Pfand |
|---|---|
| Bierflasche Glas (NRW, Euro, Longneck, Steinie) | 0,08 € |
| Bügelverschlussflasche | 0,15 € |
| Mehrweg-Glas Wasser/Saft (z. B. GDB-Perlenflasche) | 0,15 € |
| Mehrweg-PET | 0,15 € |
| Milch-/Joghurtglas | 0,15 € |
| Einwegflasche / Dose (Pfandlogo) | 0,25 € |
| Leerer Kasten | 1,50 € |
| Fass / KEG | 30,00 € |

Komplette Kästen werden automatisch berechnet (z. B. Bierkasten 20 × 0,5 l = 1,50 € + 20 × 0,08 € = 3,10 €).

**Auf dem iPhone als App installieren:** Seite in Safari öffnen → *Teilen* → *Zum Home-Bildschirm*. Mit GitHub Pages (Settings → Pages → Branch `main`, Ordner `/ (root)`) ist die App erreichbar unter `https://DEIN-BENUTZERNAME.github.io/pfand-rechner/`.
